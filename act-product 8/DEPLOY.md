# Հոսթինգ — Act Product-ը տեղադրել ինտերնետում

Կայքը ամբողջությամբ ստատիկ է (HTML + CSS + JS, առանց backend-ի),
ուստի տեղադրումը անվճար է և տևում է մի քանի րոպե։

## Տարբերակ A. GitHub Pages (խորհուրդ է տրվում)

1. Կոդը դնել GitHub ռեպոզիտորիում
2. **Settings → Pages** → Source՝ `Deploy from a branch`,
   Branch՝ `main` / `(root)` → **Save**
3. Կայքը կբացվի `https://<օգտանուն>.github.io/<ռեպո>/` հասցեով
4. Սխալ հասցեները ինքնուրույն կբացեն `404.html`-ը

## Տարբերակ B. Netlify

1. https://app.netlify.com/drop — քաշել թղթապանակը պատուհանի մեջ
2. Կայքը պատրաստ է, հղումը կտրվի անմիջապես

## Տարբերակ C. Vercel

1. Կոդը դնել GitHub-ում
2. https://vercel.com → **Add New → Project** → ընտրել ռեպոն → **Deploy**

## Հանձնելուց առաջ ստուգել

- [ ] Էջերը բացվում են, սխալ չկա
- [ ] Փորձնական պատվեր → աշխատում է, «Ընդունված է» պատուհանը բացվում է
- [ ] Սխալ հասցե → 404 էջ (որոնումն ու կատեգորիաները տանում են կատալոգ)
- [ ] Հեռախոսով ստուգված
